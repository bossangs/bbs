bk.chuhuo.top 社区论坛安装提示

完整安装说明（PHP 主机、Docker、Apache/Nginx、Windows/IIS、无伪静态及旧站升级）请阅读 DEPLOYMENT.md。

快速安装：
1. 准备 PHP 7.0–8.4、MySQL/MariaDB；启用 PDO MySQL、mbstring、JSON、zlib。
2. 创建专用数据库和用户，将程序文件上传到网站根目录。
3. 只给 conf、log、tmp、upload、plugin 目录授予 Web 运行用户所需写权限；不要将整个站点设为 777。
4. 打开 https://你的域名/install/，填写数据库和初始管理员资料完成安装。
5. 登录后台检查社区设置；邀请码注册默认关闭，可先生成邀请码再开启强制校验；评论邮件通知也默认关闭，启用前确认 SMTP。访客默认可看公开板块和公开主题；受限板块按用户组权限隐藏。发帖、回复、私信、收藏等个人操作需登录；注册和找回密码页面公开。
6. 安装完成后建议移除服务器上的 install/ 目录。不要将 conf/conf.php、.env、数据库备份或运行时上传数据发布到代码仓库。
